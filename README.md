# 🦴 Bone Tumor Clinical Data Analytics & Machine Learning

A complete end-to-end healthcare analytics project focused on bone tumor patient data using SQL Server, Python, Machine Learning, and Power BI.

---

# 📌 Project Overview

This project demonstrates a complete clinical data analytics workflow for bone tumor patients.

The objective is to transform raw clinical records into meaningful insights through:

- Data Cleaning
- SQL Data Modeling
- Exploratory Data Analysis
- Machine Learning
- Interactive Power BI Dashboard
- Clinical Reporting

The project is designed as a portfolio project for Healthcare Data Analytics.

# Clinical Insights

Key findings from the dashboard include:

- Female patients represent the larger proportion of the cohort.
- Average patient age is approximately 55 years.
- Combined treatment strategies are the most common.
- NED (No Evidence of Disease) is the dominant clinical outcome.
- Leiomyosarcoma and Synovial Sarcoma are among the most common histological subtypes.
- Tumors are primarily located in limb-related anatomical regions.
